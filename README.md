This project implements research focused on audio-based deception detection, aiming to identify truthful and deceptive speech using acoustic and machine learning techniques. The system extracts key audio features such as MFCC, Jitter, Pitch (F0), and PLP using [openSMILE](https://audeering.github.io/opensmile-python/) and [Shennong](https://docs.cognitive-ml.fr/shennong/), generating thousands of numerical representations from each speech sample. To enhance model performance, feature selection is performed using filter-based methods and Random Forest to retain only the most relevant attributes. The selected features are then used to train Support Vector Machine (SVM) and Random Forest classifiers, achieving up to 92% accuracy on the [Real-Life Trial dataset](http://web.eecs.umich.edu/~zmohamed/PDFs/Trial.ICMI.pdf) and approximately 63% accuracy on an Indonesian speech private dataset. This work contributes to the development of efficient and adaptable automatic deception detection systems based on acoustic signals, potentially applicable across different languages and contexts. This project has been published in [ITS Repository](https://repository.its.ac.id/117542/) and [JUTI Article Paper](https://juti.if.its.ac.id/index.php/juti/article/view/1250)
